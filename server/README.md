# README

Execute the following commands on separate command-line interfaces:

```shell
$ npx @electric-sql/pglite-socket --port=45432 --host=0.0.0.0 --debug=0
```

```shell
$ npx @lionweb/server-server@0.4.2-beta.3 --run --config server-config-pglite.json
```

Or – more conveniently –, run the following script:

```shell
$ ./start-lionweb-server.sh
```
