## README

In order to launch the Dockerized version:

Build the images executing the script:

```bash
./build.sh
```

Run the images with:

```bash
./start.sh
```

Repository is available at <http://localhost:40000>, and through the nginx proxy at <http://localhost:40001>

Clients available at:

* React <https://localhost:1234>
* and Daga <https://localhost:1235>

Stop with:

```bash
./stop.sh
```
